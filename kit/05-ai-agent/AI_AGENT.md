# AI-агент — следит за бизнесом и каждый день присылает отчёт

**Готов и работает.** Под тему нужно поменять только метрики, правила тревог и промпт (≈30 минут).

## Что умеет

| Функция              | Как работает                                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Мониторинг**       | Каждые `AGENT_CHECK_MINUTES` (15) мин считает метрики и проверяет правила                                               |
| **Тревоги**          | Новая `critical`/`warning` тревога → сразу в CRM (тост, WebSocket `agent:alert`) и в Telegram                           |
| **Ежедневный отчёт** | Каждый день в `AGENT_REPORT_TIME` (09:00, Ташкент): метрики → тревоги → вывод AI (главное, суть, 3 действия на сегодня) |
| **Отчёт по кнопке**  | «Сформировать отчёт» на странице `/app/agent` (admin, manager)                                                          |
| **Без AI-ключа**     | Отчёт строится по правилам — демо никогда не падает                                                                     |
| **Telegram**         | Если заданы токен бота и chat id — отчёт и тревоги уходят в чат (см. `kit/01-links/LINKS.md`)                           |
| **Первый отчёт**     | Создаётся сразу при запуске сервера, чтобы на демо было что показать                                                    |

## Как адаптировать под тему

### 1. Метрики (`metrics.js`)

Добавь поле в объект, который возвращает `computeMetrics`. Пример для ресторана:

```js
revenue24h: items.filter((i) => within(i.createdAt, now - DAY, now)).reduce((s, i) => s + (i.amount ?? 0), 0),
```

### 2. Тревоги (`rules.js`)

Добавь функцию в `RULES`:

```js
function lowRevenue(m) {
  if (m.revenue24h < 1_000_000) {
    return { key: 'low-revenue', level: 'warning', title: 'Выручка ниже нормы', detail: `За сутки ${m.revenue24h.toLocaleString('ru-RU')} сум` };
  }
},
```

И действие для отчёта без AI — в `ACTIONS` в `reporter.js`: `'low-revenue': 'Запустите акцию на вечер'`.

### 3. Промпт отчёта (`reporter.js` → `INSTRUCTION`)

Опиши роль под тему: «Ты — AI-директор сети кафе / управляющий складом / диспетчер ЖКХ…».
Формат ответа (JSON с `headline`, `summary`, `recommendations[3]`) не менять — от него зависит интерфейс.
Готовые роли — в `PROMPTS.md`.

### 4. Тест (`server/tests/agent.test.js`)

На каждое новое правило — один тест «срабатывает» и один «молчит».

## Настройки (`server/.env` и Railway Variables)

| Переменная            | По умолчанию            | Что делает                                      |
| --------------------- | ----------------------- | ----------------------------------------------- |
| `AGENT_ENABLED`       | `true`                  | Включить агента                                 |
| `AGENT_REPORT_TIME`   | `09:00`                 | Время ежедневного отчёта                        |
| `AGENT_TZ`            | `Asia/Tashkent`         | Часовой пояс                                    |
| `AGENT_CHECK_MINUTES` | `15`                    | Частота проверки тревог (для демо — `1`)        |
| `AGENT_STALE_HOURS`   | `48`                    | Через сколько часов запись считается «зависшей» |
| `AGENT_DONE_STATUS`   | `done`                  | Какой статус означает «решено»                  |
| `AGENT_COLLECTION`    | первая из `COLLECTIONS` | За какой коллекцией следить                     |
| Telegram              | пусто                   | Токен бота и chat id — по желанию               |

## Как показать на демо (30 секунд)

1. Открыть `/app/agent` — «Агент работает», последний отчёт с 3 действиями.
2. С телефона быстро добавить 3 срочные записи (приоритет 5) → приходит тревога «Много срочных нерешённых».
3. Нажать «Сформировать отчёт» → новый отчёт появляется сам, рекомендации поменялись.
4. Показать Telegram — тот же отчёт пришёл в чат.
