# AI-управляющий — AI сам управляет бизнесом, человек подтверждает голосом

**Вау-момент для жюри.** AI замечает проблему → «звонит» владельцу → голосом спрашивает «Заказать?» → человек говорит «да» → AI сам выполняет действие, и все экраны обновляются.

## Что умеет

| Функция               | Как работает                                                                                                |
| --------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Звонок**            | Товар ниже минимума → агент готовит заказ и показывает экран входящего звонка на любой странице CRM         |
| **Голос**             | Синтез и распознавание речи браузера (Chrome/Edge/Safari), без ключей. Микрофон — только по HTTPS/localhost |
| **Голосовые команды** | «Закажи 20 молока», «Создай задачу: проверить кассу», «Сделай отчёт», «Что важно сегодня?»                  |
| **Действия**          | Заказ у поставщика, задача, смена статуса, сообщение команде в Telegram, отчёт                              |
| **С AI-ключом**       | Модель сама выбирает действие (function calling / tools) по любой фразе                                     |
| **Без ключа**         | Команды разбираются правилами — демо не падает                                                              |
| **Безопасность**      | AI только предлагает, решает человек. Лимит суммы, проверка баланса, журнал «кто, когда, что»               |


## Как адаптировать под тему (≈30 минут)

1. **Действия** (`actions.js`) — переименовать/добавить под тему: «вызвать мастера», «перенести запись к врачу», «заказать корм». Шаблон: `description`, `parameters`, `schema`, `prepare`, `execute`.
2. **Что заканчивается** (`server/src/db/demoStock.js`) — товары, материалы, лекарства, запчасти. Поля: `name, unit, quantity, minQuantity, unitPrice, supplier`.
3. **Тексты** (`client/src/config/operator.js`) — имя помощника, подсказки, слова «да/нет».
4. **Настройки** (`server/.env`): `OPERATOR_NAME`, `OPERATOR_BALANCE`, `OPERATOR_MAX_AMOUNT`, `OPERATOR_CURRENCY`.
5. **Тест** на каждое новое действие — в `server/tests/operator.test.js`.

## Демо на сцене (30 секунд)

1. Телефон (вход под admin или manager) — открыта любая страница CRM. Большой экран — `/app/operator`.
2. На большом экране «Демо: продажа» → на телефоне звонит «AI-управляющий».
3. «Ответить» → AI говорит: «Заканчивается молоко… Заказать 26 шт за 312 000 сум?» → вслух «Да».
4. На большом экране: остаток вырос, деньги списаны, действие в журнале. Заказ ушёл в Telegram-отчёт.
5. Ответ жюри «а если AI ошибётся?»: AI только предлагает, решает человек; лимит суммы; всё в журнале.

**Шумный зал:** кнопки «Да / Нет» работают всегда. Перед демо один раз разрешить микрофон в браузере телефона.
