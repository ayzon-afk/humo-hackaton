# Демо-данные — чтобы на демо всё выглядело как настоящий бизнес

Данные создаются в `server/src/db/seed.js` (функция `demoItems`). Пересоздать: `npm run seed`.
На Railway данные пересоздаются при каждом деплое (файловое хранилище не постоянное) — это нормально для демо.

## Правила реалистичных данных

1. **Никаких «Демо-запись #12»** — настоящие названия под тему.
2. **Реальные места Ташкента** (см. список ниже) — жюри узнает районы, это вызывает доверие.
3. **Распределение как в жизни:** ~40% новых, ~30% в работе, ~30% решено; срочных (4–5) — около 25%.
4. **Время:** записи за последние 14 дней, больше всего — за последние 2–3 дня (видно рост на графике).
5. **История:** у решённых есть переходы статусов с разными людьми из команды — это видно в карточке записи.
6. **Цифры** (суммы, количества) — правдоподобные для Узбекистана, в сумах.
7. 25–40 записей: достаточно для графиков, не слишком много для таблицы.

  title: 'Прорыв трубы во дворе',
