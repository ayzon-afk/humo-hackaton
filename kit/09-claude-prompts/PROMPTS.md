# Готовые промпты для Claude Code — по этапам дня

Копируй блок целиком. Каждый промпт ссылается на нужные файлы `kit/`, поэтому Claude Code сразу знает правила.

---

## Этап 0. Тема объявлена (первые 10 минут)

```
Вот тема хакатона дословно: «...»
Критерии оценки: ...
Время: ...
Запиши это в kit/00-task/TASK.md (разделы 1 и 2). Потом предложи 10 идей решения:
от очевидных до неожиданных. Для каждой: кому помогает, вау-момент на демо, успеем ли за отведённое время.
Используй структуру kit/00-task/IDEA_CANVAS.md. Код не трогай.
```

## Этап 1. Идея выбрана → план

```
Выбрали идею №... Заполни kit/00-task/TASK.md полностью (разделы 3–10).
Затем составь пошаговый план адаптации проекта по чек-листу из раздела 10:
какие файлы меняем, какие сущности, поля, статусы, категории, правила AI-агента, сцены сайта.
Ничего не меняй, пока я не подтвержу план.
```

## Этап 2. Адаптация конфигов (самое быстрое — 15 минут)

```
Выполни шаги плана, которые касаются только конфигов:
client/src/config/project.js, labels.js, story.js, nav.js, server/.env (COLLECTIONS), index.html <title>.
Соблюдай CLAUDE.md. После — npm run check и покажи, что поменялось.
```

## Этап 3. Новые поля сущности

```
Добавь в сущность поля: [поле — тип — зачем].
Пройди всю цепочку как описано в kit/03-system/SYSTEM.md («Новые поля»):
zod-схема → ItemForm (используй ChoiceChips/SegmentedControl где уместно) → ItemTable → ItemDetailView.
Добавь тест на валидацию в server/tests/items.test.js. npm run check.
```

## Этап 4. Новая страница

```
Нужна страница «...»: [что на ней и зачем].
Сделай как остальные страницы CRM (kit/03-system/SYSTEM.md, kit/02-design/STYLE_CRM.md):
PageHeader + карточки, только токены, маленькие компоненты в components/<папка>/, пункт в config/nav.js.
Если нужен API — роутер + zod-схема + тест. Покажи скриншот-описание результата и npm run check.
```

## Этап 5. AI-агент под тему

```
Адаптируй AI-агента по kit/05-ai-agent/AI_AGENT.md под тему из TASK.md:
1) метрики в metrics.js, 2) 3–4 правила тревог в rules.js + действия в ACTIONS,
3) INSTRUCTION в reporter.js (роль из kit/05-ai-agent/PROMPTS.md), 4) тесты в agent.test.js.
Ничего не ломай в формате отчёта. npm run check.
```

## Этап 6. Сайт под тему

```
Адаптируй сайт по kit/04-site/SITE.md: config/project.js (слоган, цифра проблемы с источником, 3 возможности),
config/story.js (4 шага), константы-примеры в начале каждого файла components/site/scenes/*.vue.
Тексты короткие, по правилам kit/02-design/STYLE_WEBSITE.md. npm run check.
```

## Этап 7. Демо-данные

```
Перепиши demoItems в server/src/db/seed.js по kit/07-data/DATA.md под тему.
Сделай так, чтобы у AI-агента сработали 2 тревоги (например, срочные и зависшие) — это покажем на демо.
npm run seed, npm run check.
```

## Этап 8. Проверка перед деплоем (каждый раз)

```
Проверь проект по kit/06-code-rules/CODE_RULES.md: прогони npm run check, найди нарушения правил
(хардкод цветов, большие компоненты, роуты без схемы, мёртвый код, «PROJECT NAME»/«Демо-запись» в UI).
Исправь и дай короткий отчёт.
```

## Этап 9. Деплой

```
npm run check, затем npm run deploy -- "краткое описание изменений".
Дождись railway deployment list = SUCCESS и проверь https://humo-hackaton-production.up.railway.app/api/health
```

## Этап 10. Финал (последний час)

```
Подготовь питч по kit/08-pitch/PITCH.md под нашу тему: текст на 3 минуты по слайдам,
сценарий живого демо по шагам (что кликать), 6 ответов на вопросы жюри.
Обнови README: название, одна фраза, ссылка на демо, возможности.
```

## Если что-то сломалось

```
Ошибка: [вставить текст ошибки / что видно].
Найди причину, не переписывая лишнего. Исправь минимально, добавь тест, если это логика сервера. npm run check.
```
