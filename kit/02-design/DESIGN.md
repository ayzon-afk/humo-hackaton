# Дизайн — коротко (полные правила: STYLE_CRM.md и STYLE_WEBSITE.md)

**Стиль:** как Apple — дорого, спокойно, понятно без объяснений. Богатство — через пространство и типографику, не через эффекты.
**Палитра:** синий `#0071E3` + белый. Серый — только текст и фон страницы. Тёмная тема есть, по умолчанию светлая (проектор).

## Источник правды

`client/src/styles/tokens.css` — все цвета, шрифты, отступы, радиусы, тени, анимации.
Компоненты используют **только** `var(--…)`. Смена акцента = одна строка `--accent`.

## Ключевые токены

| Токен                                             | Значение                    | Для чего                                  |
| ------------------------------------------------- | --------------------------- | ----------------------------------------- |
| `--accent`                                        | #0071E3                     | главная кнопка, активное, ссылки, графики |
| `--accent-soft`                                   | синий 10%                   | фон активного пункта, AI-блоки, подсветка |
| `--bg` / `--surface`                              | #F5F5F7 / #FFF              | страница / карточки                       |
| `--text` / `--text-secondary` / `--text-tertiary` | #1D1D1F / #6E6E73 / #86868B | текст по важности                         |
| `--radius-md` / `--radius-lg` / `--radius-xl`     | 10 / 18 / 24px              | кнопки / карточки / панели                |
| `--space-1…12`                                    | шаг 4px                     | все отступы                               |
| Шрифт                                             | Inter Variable              | встроен, работает офлайн                  |

## Файлы стилей

```
styles/tokens.css          токены (свет + тьма)
styles/base.css            типографика, фокус, reduced-motion
styles/components/*.css    кнопки, поля, карточки, таблица, статусы, сегменты, сайдбар, панель, тосты, чат, таймлайн, агент
styles/site.css            сайт (крупнее, кнопки-пилюли)
styles/site-story.css      scroll-история сайта
```

## 10 правил одной строкой

1. Одна синяя кнопка на экран. 2. Статус = точка + текст. 3. Выбор — чипы/сегменты, не `<select>` (кроме длинных списков).
2. Один поиск на страницу. 5. Действия в строке — при наведении. 6. Скелетон вместо спиннера.
3. Пустое состояние = приглашение + кнопка. 8. Анимации 120–320ms, только opacity/transform.
4. Иконки Lucide stroke 1.5–1.75, без эмодзи. 10. Никаких градиентов, glow, стекла, капса.
