# Стиль CRM / системы — «Apple-элитно»

> Интерфейс выглядит дорого не за счёт эффектов, а за счёт **пространства, типографики и сдержанности**.
> Цвета, шрифты, отступы — только из `client/src/styles/tokens.css`. Хардкод цветов запрещён.

## 1. Цвет

| Роль             | Токен                                             | Где использовать                                                                |
| ---------------- | ------------------------------------------------- | ------------------------------------------------------------------------------- |
| Акцент `#0071E3` | `--accent`                                        | Главная кнопка, активный пункт меню, ссылки, фокус, одна ключевая линия графика |
| Фон страницы     | `--bg` `#F5F5F7`                                  | Под всем контентом, сайдбар                                                     |
| Карточки         | `--surface` `#FFF`                                | Карточки, таблицы, панели                                                       |
| Текст            | `--text` / `--text-secondary` / `--text-tertiary` | Основной / вторичный / подписи и даты                                           |
| Статусы          | `--success` `--warning` `--danger`                | **Только точка** рядом с текстом статуса                                        |

**Палитра бренда — синий + белый.** Серый — только для текста и фона страницы, не для «смысловых» элементов.

Синим делаем всё, что означает «выбрано / важно / данные»:

- активный пункт меню (`--accent-soft` фон + синий текст), логотип, аватар;
- выбранный сегмент фильтра и выбранный чип (сплошной синий, белый текст);
- полоски и графики (`.bar` — синий, лидер ярче, остальные светлее);
- фокус полей, ссылки, AI-блок (`.ai-assist`).

На экране **одна** сплошная синяя кнопка-действие (`.btn-primary`). Остальные — `.btn-secondary` или `.btn-ghost`.

## 2. Типографика

Шрифт **Inter Variable** (аналог SF Pro, встроен в проект — работает без интернета).

| Размер  | Токен                   | Для чего                           |
| ------- | ----------------------- | ---------------------------------- |
| 40px    | `--fs-3xl`              | Одна главная цифра на дашборде     |
| 28px    | `--fs-2xl`              | Заголовок страницы (`h1`)          |
| 22px    | `--fs-xl`               | Секции                             |
| 15–17px | `--fs-base` / `--fs-lg` | Основной текст, заголовки карточек |
| 13px    | `--fs-sm`               | Таблицы, вторичный текст           |
| 12px    | `--fs-xs`               | Подписи, метаданные, даты          |

- Веса: 400 (текст), 500 (кнопки, названия), 600 (заголовки). **700 — только на сайте.**
- Крупные заголовки — с отрицательным трекингом (`--tracking-tight`), это и даёт «дорогой» вид.
- Цифры в таблицах и метриках — класс `.num` (моноширинные цифры, не прыгают).

## 3. Отступы и форма

- Шаг сетки **4px**: `--space-1…12`. Никаких «13px» и «7px».
- Внутри карточки — 24px (`.card-body`). Между карточками — 16px (`gap-4`).
- Радиусы: кнопки/инпуты **10px**, карточки **18px**, модалки/панели **24px**.
- Тени еле заметные (`--shadow-card`). Рамки — только тонкие разделители `--hairline`.

## 5. Структура экрана

```
[Сайдбар]  │  Заголовок страницы             [ Главная кнопка ]
 логотип   │  [Сегменты фильтра]                    [ Поиск ]
 меню      │  ┌──────────── карточка ────────────┐
 ◐ тема    │  │  контент                          │
```

- Верхней панели на компьютере нет — всё в сайдбаре (тема, выход). На телефоне — полоска с меню.
- Поиск — **один** на странице, белый, рядом с фильтром. Не дублируем его в шапке.
- Не пишем очевидное («24 всего») — счётчики уже есть в сегментах.

### Форма в боковой панели

1. Крупное поле названия (без рамки, как Apple Notes) — сразу в фокусе
2. Описание
3. Синий AI-блок «Заполнить» — заполняет категорию, приоритет, название
4. Категория — чипы; приоритет — сегменты 1–5
5. Футер: «Отмена» + широкая синяя «Добавить запись»

- На дашборде **одна главная карточка** (большая цифра + тренд) шире остальных. Не делай 4 одинаковые карточки в ряд.
- Действия в строке таблицы (удалить и т.п.) появляются **при наведении**.
- Новые данные в realtime мягко подсвечиваются (`.row-new`) + тост.

## 6. Движение

- 120–320ms, кривая `--ease` / `--ease-out`. Анимируем только `opacity` и `transform`.
- Страница появляется с лёгким сдвигом снизу, панель выезжает справа.
- Учтён `prefers-reduced-motion`.

## 7. ❌ Запрещено (AI-слоп)

- Градиенты на кнопках и фонах, особенно фиолетово-розовые
- Свечение (glow), неон, цветные тени
- Эмодзи вместо иконок → только **Lucide** (`lucide-vue-next`), stroke 1.5–1.75
- 4+ одинаковые карточки-метрики в ряд
- Пастельные «пилюли» вокруг статусов, дат, тегов → точка + текст
- Серые «смысловые» элементы (полоски, выбранные фильтры) → синие
- Два поиска на одном экране, выпадающие списки там, где хватит чипов/сегментов
- Иконки внутри обычных инпутов (кроме поиска)
- Круговые/пончиковые диаграммы → горизонтальные полоски
- Стеклянные панели с размытием (`backdrop-filter`)
- Спиннеры на всю страницу → скелетоны
- Больше одной синей кнопки на экране
- ВЕСЬ ТЕКСТ КАПСОМ, жирный шрифт посреди предложения
- Текст «Успешно!», «Пожалуйста», восклицательные знаки в системных сообщениях

## 8. Тексты интерфейса

- Кнопки — глагол: «Новая запись», «Добавить», «Сохранить». Не «ОК», «Submit».
- Ошибка = что случилось + что делать: «Добавь название».
- Пустое состояние = приглашение к действию, а не извинение.

## 9. Тёмная тема

Переключатель в топбаре, выбор запоминается. По умолчанию — **светлая** (на проекторе читается лучше).
Все цвета берутся из токенов, поэтому новые компоненты автоматически работают в обеих темах.
