# KIT — всё для хакатона в одном месте

Эта папка — база знаний для Claude Code и для команды. Каждая папка — отдельная тема.

| Папка                | Что внутри                                                            | Когда открывать               |
| -------------------- | --------------------------------------------------------------------- | ----------------------------- |
| `00-task/`           | **TASK.md** (тема и решение — заполнить утром), разбор идеи, план дня | Первым делом                  |
| `01-links/`          | Репозиторий, Railway, прод, логины, AI-ключи, команды                 | Когда нужна ссылка или доступ |
| `02-design/`         | Дизайн-система, правила CRM и сайта, что запрещено                    | Перед любой вёрсткой          |
| `03-system/`         | Все страницы CRM: что на них, из каких файлов, как адаптировать       | Когда меняем систему          |
| `04-site/`           | Сайт: секции, scroll-история, тексты                                  | Когда меняем сайт             |
| `05-ai-agent/`       | AI-агент: мониторинг, тревоги, ежедневные отчёты, промпты             | Когда адаптируем AI           |
| `06-code-rules/`     | Как писать код, чтобы AI-проверка не нашла проблем                    | Всегда                        |
| `07-data/`           | Как сделать реалистичные демо-данные под тему                         | Перед демо                    |
| `08-pitch/`          | Структура питча и ответы жюри                                         | Последний час                 |
| `09-claude-prompts/` | Готовые промпты для Claude Code по этапам                             | Копировать и вставлять        |

## Первый промпт для Claude Code утром

```
Прочитай CLAUDE.md и kit/00-task/TASK.md. Тема заполнена.
Составь план адаптации проекта под тему: какие конфиги поменять, какие сущности и поля,
какие правила AI-агента, какие сцены сайта. Ничего не меняй, пока я не подтвержу план.
```
